# The poem about stopping

A short poem about agency: the power to stop and to stay. A kettle lifted
off the flame, an agent running ahead all day — and the one word it cannot
spend, the no that stays in its owner's mouth, warm as a coin. Stopping is
not the failure of the going; it is the hand, still mine, on the door.
